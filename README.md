# Stelora

SEO-focused Next.js marketing site for **Stelora** — a full-service social media marketing brand.

## Stack

- Next.js (Pages Router)
- JSX + Tailwind CSS
- Framer Motion + GSAP

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
components/   Navbar, Hero
pages/        index, _app, _document
public/images Hero & brand imagery
styles/       Global CSS variables
```
